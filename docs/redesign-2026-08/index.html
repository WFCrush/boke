wfcrush.github.io / 改版方案 · 2026.08.20

三个方向，都是同一个判断：
这本笔记本不该看起来像一个模板站。

现在的问题不是"配色不好看"，而是一篇磁浮列车故障检测论文、一段 Codex 排错记录、和一篇写祖母葡萄架的散文，在页面上长得完全一样。下面三个方案各自选了一种把它们区分开的办法。

方 案

  • A · 方格实验本

    把网站做成一本真的方格本：所有东西对齐 5mm 格线，目录里直接印出每篇论文拟合到的公式和 R²，排错用红笔批注。散文是全站唯一被允许离开格线的内容——它落在一张撕边的白纸上。

    浅色 · 思源黑体 + 思源宋体 + Consolas · 描图纸青白 / 蓝黑墨水 / 批注红
  • B · 晚风信笺

    按站名来：晚风、暮色、写给以后的自己。标题全部用楷体，每篇文章盖一枚邮戳，戳的墨色就是它的性质——井水青是论文，苔绿是折腾工具，葡萄紫是散文。

    深色 · 楷体 + 思源宋体 + 仿宋 · 夜蓝 / 葡萄紫 / 苔绿 / 井水青
  • C · 监测台

    借你自己论文里的那套语言：五个分类是五个通道，首页就是一张输出时序图，技术笔记是基线信号，那两篇散文按"异常区间"用品红标出来。列表右侧直接给每篇的关键读数。

    浅色 · 等线 + 思源黑体 + Consolas · 台面白 / 信号青 / 异常品红

现 状 诊 断

  • 01首屏 48% 高度是一张被 0.55 蒙版压成灰雾的壁纸，打字机副标题是空的。
  • 02名字有五个：导航写"晚风の技术笔记"、首屏写"ASHUWEI 的技术笔记"、侧栏写"ASHUWEI"、副标题是"Fable"、首页配置里还有个"Aurora Notebook"。
  • 03文案是模板话："记录思考，分享生活，探索无限可能。"
  • 04配色是 Tailwind 默认的 slate + blue-600，和内容没有任何关系。
  • 05卡片没有日期、没有分类、没有字数，一屏只装两篇，其中大半是空白。
  • 06正文页目录挤成两行折行（"定位""展开"竖排），右下角两个悬浮按钮叠在一起。
  • 07磁浮那篇的近似式漏了一个 $，公式没渲染出来。

三份都是静态样张，只做了首页索引和一页正文的排版，用的是你博客里真实的标题、日期和数据。选定方向后再落到 Fluid 主题的 CSS 和模板上。
