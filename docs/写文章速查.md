# 写文章速查

## 最快流程

1. 双击或运行：

```powershell
cd /d D:\BoKe
npm run new "文章标题"
```

2. 打开生成的 Markdown 文件，写正文。
3. 本地预览：

```powershell
npm run server
```

4. 发布到 GitHub Pages：

```powershell
npm run publish
```

## 文章开头

每篇文章最上面都有一段信息，叫 Front Matter：

```markdown
---
title: 文章标题
date: 2026-05-25 21:00:00
categories:
  - 分类名
tags:
  - 标签1
  - 标签2
---
```

`categories` 是分类，通常 1 个就够。`tags` 是标签，可以多个。

## 常用 Markdown

```markdown
# 一级标题
## 二级标题
### 三级标题

这是一段正文。

**加粗**
*斜体*

- 列表项
- 列表项

[链接文字](https://example.com)

![图片说明](/img/example.png)
```

## 两栏

```html
<div class="boke-columns">
  <div>

### 左边标题

左边内容。

  </div>
  <div>

### 右边标题

右边内容。

  </div>
</div>
```

## 三栏

```html
<div class="boke-columns" style="--columns: 3;">
  <div>

### 第一栏

内容。

  </div>
  <div>

### 第二栏

内容。

  </div>
  <div>

### 第三栏

内容。

  </div>
</div>
```

## 卡片分栏

```html
<div class="boke-columns">
  <div class="boke-card">

### 优点

- 简洁
- 好看
- 手机上会自动变成一栏

  </div>
  <div class="boke-card">

### 缺点

- 内容太多时要注意排版

  </div>
</div>
```
